# SQL-Book-Store-Project

## Project Overview
This project demonstrates SQL-based data analysis using a relational Book Store database.

- PostgreSQL

## Database Tables
- Books
- Customers
- Orders

## SQL Concepts Covered

- WHERE
- GROUP BY
- HAVING
- ORDER BY
- JOINS
